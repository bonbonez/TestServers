# TestServers

Repo with multiple test servers for testing

## Structure

Area-specific rules live in `docs/agent-rules/` (one file per area) and are imported below.
Follow the file(s) relevant to what you're touching:

- **Client** — the React frontend apps under `apps/` (e.g. `apps/oauth-login-web/`)
- **Server** — the Node/TypeScript backend apps under `apps/` (e.g. `apps/mcp-server/`, `apps/oauth-server/`)
