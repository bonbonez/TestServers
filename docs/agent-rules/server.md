# Mandatory guidelines for Agent  development

This document is a set of rules that should be followed when developing the Agent API. These rules are mandatory and
should be adhered to in order to maintain consistency and quality across the application.
These rules are only applied to code inside the client directory.

## Code style.
- Always focus on making beautiful and readable code.
- Do not make single-use simple functions, always inline code.
- Never make same-line return statements.
